## 📂 Projects

### 1. E-Commerce Sales Analysis and Dashboard | SQL + Power BI

**Problem:** Understand the sales performance of an e-commerce store and present useful insights through a dashboard.

**What I did:**
- Analyzed 1,200 orders in MySQL using aggregation, GROUP BY, HAVING, CASE WHEN, subqueries, JOINs, CTEs and window functions.
- Cleaned order dates that came in two different formats.
- Built a Power BI dashboard with KPI cards, DAX measures, slicers and four charts.
- Compared Power BI totals with SQL results to confirm they match.

**Key insights:**
- Total sales: 1.51M
- Average order value: 1.26K
- Top category: Home Decor
- Top country: USA
- Peak sales month: July
- About 66% of orders are low value, which suggests an opportunity for product bundling and upselling.
- November is excluded from the monthly trend because the data ends on 1 November 2025 and has only 5 orders for that month.

**Tools:** MySQL, Power BI, DAX, Power Query

### 2. Superstore Sales & Profitability Dashboard | Excel

**Problem:** Identify which regions, categories and segments contribute most to sales and profit.

**What I did:**
- Cleaned the data and created Pivot Tables and Pivot Charts.
- Built an interactive dashboard with slicers.
- Created KPI cards for sales, profit, orders, discount and profit margin.

**Key insights:**
- Total sales: 1,49,15,600
- Total profit: 15,21,767
- Total orders: 5,496
- Profit margin: 10.20%
- West region contributes 24.12% of total sales.
- Furniture has high sales (5.18M) but very low profit (0.12M), so its discounts and costs should be reviewed.

**Tools:** Microsoft Excel, Pivot Tables, Pivot Charts, Slicers
